The first physical-AI loop

1 · Teleoperate

You command joint positions. On real hardware, a leader arm or gamepad produces these values.

2 · Record

This browser stores joint positions and relative timing in memory for replay. A real learning dataset would also include camera observations.

3 · Replay & inspect

Replay lets you inspect the recorded trajectory. Later, a policy such as ACT can learn to predict actions from observations.

What this simulation models

Forward kinematics: each rotary joint transforms the links after it; the gripper changes jaw opening. This is useful for learning poses and reach.

What comes with the real arm

Motor limits, backlash, camera calibration, collisions, latency and failures. Those messy details are where physical AI becomes real engineering.
